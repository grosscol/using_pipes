Intermediate Files

Process depth files 1M bp at a time.

NWD001.depth.gz NWD002.depth.gz NWD003.depth.gz
tabix NWD001.depth.gz "chr1:1-1000000" > 1_p1.tsv
tabix NWD002.depth.gz "chr1:1-1000000" > 2_p1.tsv
tabix NWD003.depth.gz "chr1:1-1000000" > 3_p1.tsv

aggregate.sh 1_p1.tsv 2_p1.tsv 3_p1.tsv

Named Pipe Instead of Files

mkfifo pipe1 pipe2 pipe3

tabix NWD001.depth.gz "chr1:1-100000" > pipe1 &
tabix NWD002.depth.gz "chr1:1-100000" > pipe2 &
tabix NWD003.depth.gz "chr1:1-100000" > pipe3 &

aggregate.sh pipe1 pipe2 pipe3

Current Use in Data Prep

PIPES=()
PIPE_COUNT=0

for INFILE in ${INFILES[@]}
do
  PIPE_NAME=pipe_${PIPE_COUNT}
  mkfifo ${PIPE_NAME}
  PIPES+=( ${PIPE_NAME} )

  # Start reading depth file into pipe
  (tabix ${INFILE} ${CHROM}:${POS}-${END} > ${PIPE_NAME}) &

  let "PIPE_COUNT = PIPE_COUNT + 1"
done

Nextflow Dustbusting

Nextflow has clutter reducing options as well.

  • scratch directory
  • process outputs

Process Outputs

When a process is invoked, each process output is returned as a channel. Those channels can be different things:

val: Emit the variable with the specified name. tuple: Emit multiple values. path: Emit a file produced by the process with the specified name.

Process Use

process select_sample {
   input:
   val(bcf_entry)

   output:
   tuple val(sv_id), val(sample_id)

   script:
   def sv_id = parse_sv_id( bcf_entry )
   def sample_id = select_samples( bcf_entry, 1)
}

workflow {
  sv_bcf = channel.fromPath('structvars.bcf')

  bcf_entries = read_bcf( sv_bcf )
  sv_singles = select_samples( bcf_entries )
}

Scratch Space

The scratch directive executes each task in a temporary directory that is local to the compute node.

This means only the input and output files are staged to the nextflow workspace. The intermediate files are cleaned up when the process completes.

Scratch Use

process messy_chops {
  scratch true

  input:
  path(bcf)
  path(cram_dir)

  output:
  path("depths.tsv")

  script:
  """
    # Makes many intermediate files
    #   before a final output depths.tsv
  """
}
