# Nextflow Dustbusting

Nextflow has clutter reducing options as well.

- scratch directory
- process outputs

## Process Outputs

When a process is invoked, each process output is returned as a channel. Those channels can be different things:

> val: Emit the variable with the specified name.
  tuple: Emit multiple values.
  path: Emit a file produced by the process with the specified name.

## Process Use

```txt
process select_sample {
   input:
   val(bcf_entry)

   output:
   tuple val(sv_id), val(sample_id)

   script:
   def sv_id = parse_sv_id( bcf_entry )
   def sample_id = select_samples( bcf_entry, 1)
}

workflow {
  sv_bcf = channel.fromPath('structvars.bcf')

  bcf_entries = read_bcf( sv_bcf )
  sv_singles = select_samples( bcf_entries )
}
```

## Scratch Space

> The `scratch` directive executes each task in a temporary directory that is local to the compute node.

This means only the input and output files are staged to the nextflow workspace. The intermediate files are cleaned up when the process completes.

## Scratch Use
```
process messy_chops {
  scratch true

  input:
  path(bcf)
  path(cram_dir)

  output:
  path("depths.tsv")

  script:
  """
    # Makes many intermediate files
    #   before a final output depths.tsv
  """
}
```
